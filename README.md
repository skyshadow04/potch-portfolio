# Software developer portfolio

A responsive, single-page portfolio template built with Next.js, React, and CSS.

## Personalize the template

- Update the sample name, introduction, project details, skills, locations, and social links in `app/page.tsx`.
- Replace `cpotchollo@gmail.com` with your preferred contact email.
- Update the page title and description in `app/layout.tsx`.
- Adjust the color variables and responsive styles in `app/globals.css`.

Project screenshots are stored in `public/InventoryScreenshots/` and `public/LocalNVRScreenshots/`. Update the image paths in `app/page.tsx` to use your own screenshots.
Click a project preview to open its screenshot gallery. Use the arrow buttons or keyboard arrow keys to browse images; each screenshot has its own caption.

Use the sun and moon buttons in the header to switch between light and night mode. Your selection is saved in this browser.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio. Run `npm run lint` and `npm run build` to check the project.
